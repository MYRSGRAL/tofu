# tofu

Проект нативного прокси-клиента с открытым исходным кодом: Linux первым, Android следующим этапом. Xray-core и sing-box, TUN, Fake DNS и маршрутизация по приложениям.

Статус: проектирование, реализации приложения пока нет.

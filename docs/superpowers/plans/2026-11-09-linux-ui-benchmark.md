# Выбор и оптимизация UI для Linux

Пользователь подтвердил Linux в целом и максимальную оптимизацию. Qt Quick/CXX-Qt
остаётся действующим прототипом, GTK4 и Slint — кандидатами для сравнения. GTK3
не выбран основой нового UI. Утверждения о превосходстве без замеров не делаются.

1. Общий Rust backend, одинаковые данные и семантика: 1 000/10 000 серверов,
   страницы по 200, виртуализация, поиск/сортировка/переключение страницы. Пустое
   окно и список всех строк без пагинации не являются эквивалентом текущего Qt.
2. Минимальные оболочки кандидатов, одинаковые действия и проверки результата.
   Тесты кириллицы, клавиатуры, fractional HiDPI, буфера обмена, tray-host и
   явного fallback при отсутствии трея. Никакой бизнес-логики в оболочках.
3. Cold/warm startup, поиск/скролл, 15 минут visible idle и 15 минут скрытого UI.
   PSS/USS, CPU time, wakeups/redraw, GPU при доступных счётчиках. GUI/controller,
   tray-host и proxy core учитываются раздельно и суммарно. Connected idle имеет
   тот же engine-only baseline, настройки и трафик.
4. Минимум три повтора: разброс, renderer/драйвер, Wayland/X11, DE, toolkit,
   toolchain, параметры release и упаковки, питание и фоновые процессы. Сырые
   метрики и команды сохраняются вместе со сводкой; аппаратные счётчики не
   заменяются оценкой RSS. Основные DE: KDE Plasma, GNOME, Xfce.

На текущей машине доступны Qt 6.11.2, GTK4 4.22.5 и GTK3 3.24.52. Инвентаризация
не является результатом benchmark. Xvfb/Weston и аппаратные инструменты профиля
в PATH не обнаружены; заблокированная Wayland-сессия и offscreen smoke не
доказывают реальное энергопотребление. Установка/смена DE или разблокировка
сессии не выполняются автоматически. G-UI/G-POWER остаются открытыми.

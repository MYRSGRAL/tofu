# Пакетные TCP-серии

Основание: приёмка пакета из 10000 проверок в validation-and-roadmap.md.
Добавить scheduler поверх check_tcp_series без новых runtime, фоновых timers
или изменения GUI. До 10000 целей с уникальным opaque ID, параллелизм 1..32,
общий timeout каждой серии 0<t<=60s. Результаты передаются ограниченным mpsc;
ожидание потребителя отменяемо. Cancellation clone используется каждой серией.
FuturesUnordered содержит только ограниченное число futures; Drop освобождает
сокеты сразу, без spawn отдельных задач. Receiver closure завершает пакет.

Проверить TDD: валидация, ID, лимит активных futures, backpressure, отмена во
время работы/доставки, drop всего batch future, отсутствие пропущенных результатов.
Нагрузочный fixture использует только собственные loopback listeners, не реальные
подписки. 10000 серий — 30000 TCP соединений без payload. Не заявлять закрытие
всего G-PROBE или GUI/энергоприёмки. Затем review, MSRV1.85.1, CI и merge.

## Отрицательные и неполные результаты

Native DNS lease report фиксирует сохранение mapping после TTL; это **не** доказательство
нарушения production epoch fence и не полный D-07 PASS. Startup #115 UNKNOWN,
#112 NoGo, #120 mixed compiler Unsupported, #122 permission pending сохраняются
явно. Синтетический editor Explain не наблюдает реальный поток; native G-APP
baseline не доказывает production helper Apply. Поэтому ни один полный Linux gate
здесь не повышен до proven.

# Проверка полноты встроенных RU/EN-пар GUI

Base: `21aba59f7e161a67d98ebe7415315e3fb8afcf9a`.
Область: текущий `crates/yonik-desktop/qml/Main.qml`.
AGENTS.md и CONTRIBUTING.md в checkout не найдены; применены инструкции задания,
rust-patterns и maintain-task-progress. Основной checkout не изменялся.

Переводы реализованы через `tr(ru, en)` и шесть JS-карт пар:
statusText.values, probeResultText.kinds, tcpStatusText.values,
reviewText.reasons, reviewText.fields, errorText.messages. Qt TS не используется.
Каждая запись карты одновременно задаёт ключ для RU и EN; отсутствие одного
языка нарушает структуру пары. Отдельных списков ключей по языкам нет.

Новая проверка токенизирует QML (строки и комментарии различаются), разбирает
каждую const-карту и каждый tr-вызов. Проверяет ровно два строковых значения,
непустой текст обоих языков, уникальность ключей внутри карты и равенство
мультимножеств placeholders (%1/%L1/%n, {name}, ${name}).
Неподдерживаемая форма вызова или карты вызывает ошибку, пустой каталог отклоняется.
Для текущих динамических вызовов разрешены пары pair/reason/field[0,1].

## Результат

- `python tools/check_translations.py`: 162 inline-пары, 76 ключей карт, успех.
- `python -m unittest discover -s tests -p test_check_translations.py`: 5 тестов,
  успех; включены synthetic missing-language, пустые переводы, дубликаты ключей,
  лишние элементы, неизвестные динамические вызовы и placeholder mismatch,
  включая повторение placeholder.
- `ruff format` и `ruff check` двух новых Python-файлов: успех.
- `cargo fmt --all --check`: успех.
- Python 3.14.7; используются возможности стандартной библиотеки Python 3.12+.
- Реальных структурных несоответствий текущих пар не обнаружено; QML не изменён.
- Rust не изменялся: clippy и Cargo tests не запускались, desktop/Qt не собирался.
  Cargo target не создавался. Новых зависимостей проекта нет.

## Границы доказательства

Проверка подтверждает паритет существующих пар, а не качество перевода и не
визуальную приёмку переключения языка. Полное удаление записи сразу для обоих
языков не обнаруживается как пропущенный backend-код: общего реестра message-key
пока нет. Строки вне tr и карт (бренды, протоколы, технические детали, backend
сообщения и конкатенации динамических значений) не являются каталогом этой
проверки. Связность динамических переменных с картами не доказывается анализом
потока данных. Новые QML-файлы и другой механизм локализации требуют расширения
проверки. Это текстовый срез P11, весь P11 не закрыт.

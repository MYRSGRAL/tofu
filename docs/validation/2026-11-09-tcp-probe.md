# Ручная проверка TCP: границы и evidence

Реализация FR-09: один ручной connect до endpoint выбранного ParsedServer, без
proxy authentication/payload. DNS и TCP имеют отдельные длительности и общий
пятисекундный deadline. TCP-сокет закрывается сразу после connect; это не HTTPS,
пропускная способность или проверка credentials.

## Контракт

- IP literal пропускает DNS. Имена разрешаются через systemd-resolved Varlink,
  сохраняя системную DNS-маршрутизацию. Нет getaddrinfo thread или внешнего DNS
  fallback. При отсутствии native resolver возвращается отдельный результат.
- JSON/NUL reply ограничен 64 KiB/64 адресами, адреса валидируются и дедуплицируются.
  IPv6 link-local сохраняет scope ifindex. Root-anchored metadata и peer UID
  проверяются до отправки имени; root peer socket activation разрешён.
- Не более двух параллельных connect futures, семейства чередуются. Остаток общего
  бюджета делится между парами адресов: зависшие попытки освобождают слот для
  следующих. Отмена/deadline дропают все принадлежащие проверке сокеты/futures.
- QUIC и неизвестный transport возвращают NotApplicable до I/O. DNS failure,
  resolver unavailable, connect failure, DNS/connect timeout и cancel различаются.
- Actor держит одну задачу TCP. Отдельная priority CancelTcp обходит полную очередь
  и инвалидирует queued TCP requests, сохраняя активную proxy-сессию. Stop/Shutdown
  отменяют также TCP; closed ждёт её завершения. Проверка не запускает core.
- Callback связан с source/profile/revision и generation; смена выбора очищает
  старый результат и отменяет устаревшую задачу. Cancel generation не даёт позднему
  успешному callback заменить отмену. DTO содержит только endpoint/name/time и
  enum-результат, без credentials и исходной URI.

## Проверки

Пятнадцать hermetic network-тестов: literal connect/EOF без payload, refused,
deadline, fake resolver→loopback, malformed/oversized/empty/too-many records,
отмена/timeout DNS с закрытием Unix socket, IPv6 scope/dedup, interleave,
один/два blackhole, освобождение attempt guards, UDP/no-I/O и trusted peer UID.
Отдельный environment-dependent тест явно выполнен на реальном systemd-resolved:
localhost → собственный TCP listener → EOF. Внешний DNS не использовался.

Одиннадцать actor-тестов прошли. Новые проверки: reachable/refused не изменяют
Disconnected proxy state и не запускают core; DNS для IP отсутствует; result
содержит profile/revision/time, очищается при смене выбора. Gate удерживает actor
после spawn перед polling TCP future, затем меняет профиль до обработки callback.
Отдельный тест заполняет 128 queued commands и подтверждает CancelTcp/инвалидацию
старой проверки. URI/password отсутствуют во всех полученных snapshots.

QML отдельно загружен с mock bridge при 820×620: вертикальная прокрутка, IPv6,
отдельные DNS/TCP времена, RU/EN и cancel при global busy проверены без warnings.
Этот mock не подменяет интеграцию с Rust и живой Wayland.

Release GUI smoke прошёл четыре сценария: literal reachable, resolver unavailable
в user namespace, localhost через реальный resolver в исходном UID-пространстве,
refused после закрытия listener. Проверены два реальных EOF без payload и closed.
В user namespace host UID становится 65534: root-anchoring намеренно отклоняет его;
правило доверия не ослаблено ради теста. Native DNS сценарий не запускает core.

Шесть HTTPS GUI сценариев с реальными Xray/sing-box повторены с дополнительной TCP
проверкой во время Connected/Limited. Исходный HTTPS-status сохраняется, TCP
достигает peer, Stop → Disconnected → closed. Отдельный `tcp-basic --no-namespace`
прошёл literal/refused без systemd resolver и ядер; этот hermetic шаг добавлен в CI.
Whitelist trace содержит только enum TCP status/busy, без host/name/credentials.

Workspace: Rust 1.85.1 — 166 Rust-тестов и 4 doctest прошли, три environment-dependent
теста ignored в общем прогоне; production localhost выполнен явно отдельно.
Workspace/GUI clippy с `-D warnings`, fmt, workspace/GUI release и Android
default-feature check прошли. QML lint без предупреждений; Python ruff 0.17.4 format/check и четыре unit-теста
прошли. Vendor QChar warning Qt6.11/GCC16 не объявляется чистым C++ baseline.
Evidence: `local/validation/tcp-probe`, `tcp-probe-health`, `tcp-probe-ci` — JSONL,
results.json и собственные PNG. PNG localhost показывает отдельные DNS/TCP, имя,
endpoint, timestamp и Disconnected proxy state; экран рабочего стола не снимался.

## Исправления независимого review

- P1: socket owner systemd-resolve UID 974 и SO_PEERCRED root UID 0 расходятся из-за systemd
  socket activation. Проверка равенства ошибочно запрещала production resolver.
  Теперь root/service UID допустимы после проверки metadata, чужой UID отвергается.
- P2: два pending connect ранее блокировали третий адрес до host timeout. Новый
  regression-тест воспроизвёл failure до исправления; per-attempt budget освобождает
  слоты, поздний доступный адрес достигается при сохранении лимита двух попыток.
  Узкий повтор review закрыл обе находки, новых связанных findings нет.

## Открытые границы

Результат один, привязан ко времени; история и network-generation пока отсутствуют.
UI прямо сообщает, что сеть не отслеживается. Это не рейтинг после смены Wi-Fi.
Прямой socket использует обычный маршрут ОС; интеграция с bootstrap routes будущего
TUN ещё требует доказательства. Реальная тестовая подписка проверена отдельно через stdin-only diagnostic example;
  ссылка/исходник/credentials не записывались в файлы/argv/logs.
Предоставленный тестовый источник загружен в память, импорт принял две записи и отклонил одну.
Две принятые записи переданы отдельному процессу `examples/tcp_probe.rs` через
stdin: обе Reachable; DNS отсутствовал для первой и занял 100 мс для второй,
connect округлился до 0 мс. Это только TCP без auth/HTTPS; неисправные outbound
из прошлых проверок этим не объявляются здоровыми. Safe summary сохранён в
`local/validation/tcp-probe/provider-summary.json`, без URL/host/credentials.

Живой Wayland, clipboard/keyboard, трей и HiDPI остаются открытыми. Полная спека и
G-POWER не объявляются выполненными по одному TCP smoke.

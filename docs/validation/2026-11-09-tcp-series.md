# Серия TCP-проб и медиана

Основание — FR-09 и три выборки одного endpoint в плане приёмки задержки.
Публичный одиночный `check_tcp` сохранён с прежней семантикой длительности всей
гонки адресов. Новый `check_tcp_series` используется ручной проверкой desktop.
Это диагностика TCP, не DNS provenance, proxy-аутентификация или измерение
пропускной способности. Полный G-PROBE не закрывается этой проверкой.

## Поведение

DNS разрешается один раз, если endpoint не IP literal. Первая успешная попытка
существующей ограниченной гонки выбирает полный SocketAddr; её собственное время
становится первой выборкой. DNS, stagger и ожидание других адресов в неё не входят.
Проигравшие futures уничтожаются. Ещё два соединения последовательно идут к тому
же IP, порту и IPv6 scope; все успешные сокеты сразу закрываются без payload.
Сначала одновременно не больше двух попыток, после выбора адреса — одна.

Исходный timeout ограничивает всю серию; desktop использует пять секунд вместе
с DNS. Первая ошибка/отмена/timeout останавливает серию, сохраняет частичные
выборки и причину, но не медиану. Медиана вычисляется только для трёх успехов,
сортировкой массива из трёх Duration без дополнительной heap-аллокации.
Debug результата скрывает выбранный адрес.

Desktop DTO содержит `samples_ms`, `samples_requested`, `selected_address`;
`connect_ms` теперь означает медиану трёх успешных проб. RU/EN подпись явно
показывает медиану и количество выборок. При поздней отмене generation guard
удаляет samples/median/address; при смене профиля или наблюдаемой сети старый
результат не публикуется. Неполное наблюдение сети отображается отдельно; TCP
серия не доказывает полный атомарный NetworkHost/DNS epoch контракт.

## Проверки

До реализации core-тесты не собирались из-за отсутствия API. Новая desktop
проверка падала на отсутствующем массиве трёх выборок; Python fixture-тест
выявлял закрытие listener после прежнего числа соединений. После реализации:

- Rust 1.85.1: полный workspace Clippy `--all-targets -- -D warnings`,
  форматирование и 277 workspace tests прошли; шесть существующих тестов
  требуют отдельных условий и помечены ignored в обычном запуске.
- Отдельно выполнен обновлённый route-change тест в собственных user/net/mount/PID
  namespaces: после трёх проб прежний результат инвалидируется сменой маршрута,
  новая серия имеет новый network stamp; pending/late result не восстанавливает
  старый успех, автоматические серии не запускаются. Host сеть не менялась.
- Core: один DNS-запрос, literal IPv4/IPv6, полный scope/port через connector seam,
  отсутствие DNS/stagger в sample, общий deadline DNS+connect, частичный сбой,
  cancel разных стадий, медиана различных длительностей, loser Drop, пределы
  futures и три EOF без payload. Пакет на Rust 1.97.0 — 159 passed/5 ignored.
- Desktop: 5 unit и 14 integration tests прошли; проверены три EOF, медиана и
  адрес в DTO, выбор другого профиля, CancelTcp/Stop/Shutdown. Отдельный DTO-тест
  не позволяет cancelled/incomplete result опубликовать сохранённую median.
- Python: 80 тестов, Ruff 0.17.4 check/format прошли. Сетевой fixture-тест
  использует шесть собственных loopback-соединений для двух reachable-сценариев,
  не запускает GUI, proxy core или внешнюю сеть.
- Qt offscreen/software smoke прошёл `tcp-literal` и `tcp-refused`: trace
  подтверждает 3/3, собственный screenshot показывает медиану/адрес; fixture
  принимает три соединения и проверяет EOF без payload. Это functional QA
  текущего прототипа, не измерение native Wayland или энергопотребления.

Rust 1.85.1 установлен рядом с прежними toolchain, без self-update/default change.
Первый download завершился timeout; повторный официальный install успешен.

## Ревью и ограничения

Независимые core и desktop review не нашли actionable findings. Scoped IPv6
проверен через connector seam с локальными сокетами, реальные link-local маршруты
не проверялись. Timing tests используют wall clock и чувствительны к сильной
нагрузке CI. Очистка всех полей поздней отмены проверена по коду, а запрет
публикации её медианы — отдельным DTO-тестом; детерминированного actor-теста
всех межпоточных interleavings нет.

Native GUI, G-UI/G-POWER, пакет из 10000 проверок, полная HTTPS error attribution,
DNS/Fake-IP/epoch provenance и полный G-PROBE остаются открытыми. Выбранная
компоновка А ещё ожидает toolkit-замеров в разблокированной сессии. Результаты
и собственные screenshots находятся в `local/validation/tcp-series-*`, вне Git.

## Release-кандидат

Rust 1.85.1 release GUI собран; на текущих Qt 6.11.2/GCC 16 остаётся системное
предупреждение QChar SFINAE, Rust/clippy ошибок нет. Повторный offscreen smoke
release прошёл literal/refused с тремя EOF. Бинарник сохранён в
`local/artifacts/tofu-desktop-bc7e0af/` с SHA-256 manifest и ldd, отсутствующих
библиотек нет. Это кандидат текущего функционального прототипа, а не новый дизайн А.
Генерируемый qmlls.ini исключён из Git и удаляется перед очисткой собственного
build-каталога, чтобы не оставлять устаревшие ссылки IDE на transient paths.

Дополнительный regression-тест показал: OS `TimedOut` второй пробы ошибочно
получал ConnectFailure. Исправлено сохранение ConnectTimeout; отказ и отмена
по-прежнему имеют отдельные статусы. После изменения повторно прошли полные
Clippy/workspace tests на 1.85.1 и incremental release build. Частичные выборки
не превращаются в медиану при любом из этих исходов.

# yonik: ребрендинг и навигация

Проверка ветки `fix/desktop-hwid-ui` относительно `cae853a`.

## Изменения

- Репозиторий: https://github.com/MYRSGRAL/yonik.
- Приложение, crates, CLI, Qt module, иконка, меню, инструменты и актуальные README EN/RU используют yonik.
- Окно 420×760, минимум 380×600; постоянные разделы подключения, серверов и настроек.
- Избранное удалено из GUI; сохранённые данные и backend API совместимы.
- Подписки управляются на экране серверов: добавить, вставить, обновить, переименовать, удалить, отменить загрузку. Отмена использует непрозрачный строковый token.
- Ошибки подписок и соединения независимы; неудачный импорт сохраняет фильтр, успешная смена источника сбрасывает его.
- Установщик переносит управляемое старое меню после успешной записи нового; чужие файлы сохраняются. Иконка удаляется первой, entry последним, чтобы повтор завершал прерванную очистку.

## Совместимость

Сохранены legacy-каталог данных `tofu`, Secret Service attributes и creation lock,
криптографические domains/sentinel, IPC prefix от canonical data-dir, Polkit action IDs
и контракт имён управляемых TUN-ресурсов. Живая SQLite не копируется в новый каталог.
Существующая БД без ключа по-прежнему отклоняется. Миграция SQLite v3 добавляет
монотонную последовательность source ID. Regression fingerprint использует
синтетический известный вектор; пользовательские ключи для тестов не читаются.

## Проверки

- Rust 1.85.1: 366 тестов workspace, 0 failures, 7 ignored.
- Python: 99 unittest; pinned Ruff format/check.
- Модель UI benchmark: 8 тестов.
- Release GUI: по 132 действия на 420×760 / 100% и 380×600 / 150%, по 15 captures.
- В каждом GUI-сценарии: 7 синтетических HTTP-запросов, opt-in HWID без утечки в trace,
  отмена медленной загрузки, 3 TCP EOF; 5 ошибочных scripts отклонены.
- HTTPS health: 6 сценариев Xray/sing-box, ожидаемый 204, неожиданный 200 и настроенный 200;
  штатная остановка и завершение собственных процессов.
- Независимое compatibility review: findings нет; проверены legacy-константы,
  Cargo.lock, resource/module names, token и повтор установки. Секреты и реальная БД
  reviewer не использовал; полный UX подтверждён автоматическими GUI-сценариями.

Найдены и устранены перед публикацией: присваивание read-only Flow.implicitHeight;
лимит smoke steps для расширенного сценария; тест ожидал старую ошибку после
изменения параметров соединения — теперь повторяет попытку до проверки scopes.

## Ограничения

Приложение остаётся локальным SOCKS-клиентом. Полный системный TUN, общие замеры
Qt/GTK/Slint в разблокированной сессии и доступность каждого удалённого сервера
этим прогоном не подтверждаются. Исторические отчёты прежних сборок не переименованы.
Синтетические screenshots/logs находятся в игнорируемом `local/validation/whole-ux`.

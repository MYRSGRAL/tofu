# Настройка локального SOCKS-порта

Backend `DesktopHost` принимает `set_listen_port` с целым ненулевым `u16`.
Настройка изменяет порт следующего подключения в текущем сеансе host; сохранение
между запусками не реализовано. При активной сессии или неподтверждённой очистке
(`can_stop=true`) возвращается `busy`, прежний порт сохраняется. Setter не
открывает listener и не определяет занятость порта. Основной GUI ещё не вызывает
команду; она подготовлена для выбранного экрана А.

## Проверки

До реализации два новых интеграционных теста падали с `invalid_input`, unit test
не мог разобрать неизвестную команду. После реализации на Rust 1.97.0 прошли:

- 4 unit tests и 14 integration tests `tofu-desktop`.
- Валидация нуля, переполнения, отрицательного значения, строки, bool, дроби,
  null, отсутствующего порта и неизвестного поля; границы 1 и 65535 приняты.
- Применение занятого собственного loopback-порта не выполняет bind.
- `reload` не сбрасывает порт. Следующая смена engine служит FIFO-барьером:
  случайный snapshot сетевого наблюдателя не выдаётся за ack перечитывания.
- Следующий `connect` использует новый порт: прежняя конфигурация доходит до
  `engine_missing`; совпадение нового loopback listener с endpoint отклоняется
  настоящим compiler как `engine_config` до запуска ядра. Публичная сеть и
  установленные engine binaries этому тесту не нужны.
- Private Actor test проверяет запрет изменения при удерживаемой сессии в
  Preparing/Connected/CleanupError и разрешение после её освобождения.
- `cargo fmt --all -- --check` и scoped clippy `-p tofu-desktop --all-targets
  --no-deps -- -D warnings` прошли. Тестовые каталоги создаются эксклюзивно с
  0700 до получения cleanup ownership.

## Ограничения

Существующий network-namespace integration test не запускался: он требует
отдельного `unshare` и не связан с изменённой настройкой. Native GUI не проверялся
и не менялся. Контракт экрана А описан в `docs/specs/ui-backend-contract.md`.

Локального Rust 1.85.1 нет; проверка production MSRV остаётся за CI. Полный clippy
на локальном Rust 1.97 останавливается на существующем `collapsible_match` в
`tofu-engine/src/lib.rs:161`; этот участок не менялся. Проверка изменённого
пакета с `--no-deps` чистая. Не выдавать её за полный workspace clippy или
прохождение production MSRV.

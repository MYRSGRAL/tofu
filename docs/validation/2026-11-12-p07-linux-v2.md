# P07 Linux: typed selector, Draft V2 и enforced format4 barrier

Linux scope: хранение AndroidPackage как cross-platform данных; Android runtime,
физические G-UI/G-POWER не реализуются и не заявляются принятыми.
База — ordinary merge main `1cd4a32db5b2c889039661ce0657eff0a3031842`;
самостоятельный coherent repository/API HEAD —
`010242a8ee06a18b4656a42c4451a802d36a85e3`.

## Контракт

Закрытый PlatformSource::AndroidPackage содержит проверенный AndroidPackageId.
ASCII 3–253 bytes, минимум два непустых сегмента; ASCII letter в начале сегмента,
дальше letter/digit/underscore, без нормализации регистра. Ни PID/Exec mapping,
ни raw/native/Other/flatten selector не добавлены. Новых dependencies/unsafe нет.
Draft V2 требует platform_sources в каждом правиле; V1 сериализуется прежним
образом до первого реального selector. Лимиты: 16/rule, 256 rules, 4096 sources,
262144 raw bytes, 200000 selector bytes. Duplicate/unknown kind/field/version и
null вместо массива отклоняются; unreadable blob остаётся read-only.

Enabled selector возвращает UnsupportedSelector(rule ID) до user/LAN/default,
обоих native compiler outputs и SystemPolicy/Prepare. Explain проверяет это до
application witness и возвращает reason + ID. Disabled selector сохраняется в
Draft/Conditions/SystemPolicy V2 и не влияет на обычный маршрут. Main.qml получает
только indication и hidden DTO hooks; load/duplicate делает deep copy, reset
очищает selector нового правила, simple/advanced layout не менялся.

## Миграция и совместимость

Первый V2 write требует реальную verified closed backup v3 через существующий
maintenance-flow. Repository сравнивает ID, schema/AEAD и полное содержимое backup
с live snapshot внутри IMMEDIATE транзакции. CAS и PRAGMA user_version=4 коммитятся
вместе; missing/self/stale backup и отмена/fault откатывают данные, revision и
формат. Format4 не понижается автоматически. Rollback старому app — явный restore
предмиграционной backup v3 в новый путь; backup/restore format4 сохраняет format4.
[Согласованный barrier и API W3](2026-11-12-p07-repository-barrier-proposal.md).

NativeBroker ABI 260, broker feature bits, pins/capabilities не изменялись.
Policy wire V2 — закрытая additive schema; V1 не может принять V2 selector с
потерей данных. Старый broker policyDigest остаётся opaque. IPC error context V2
не менялся. Connect использует существующий unsupported_option и отдельно
отказывает при unreadable Draft до Prepare/worker.

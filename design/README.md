# Варианты интерфейса tofu

Откройте `ui-variants.html` в браузере. Это автономный прототип на HTML/CSS/JS, без фреймворков, сетевых запросов и сборки. Три варианта показываются переключателями над окном:

- **А — «Один фокус»**: вертикальная композиция и крупная кнопка питания.
- **Б — «Рядом»**: сервер слева, подключение справа; узкое окно складывается в колонку.
- **В — «Под рукой»**: компактная композиция с быстрым выбором избранного.

Карточка сервера открывает поиск по трём демонстрационным странам/городам. Звёздочки меняют избранное, которое доступно в варианте В. Кнопка питания переключает демосостояние. Шестерёнка открывает отдельный экран настроек; назад можно вернуться стрелкой или Escape. Кнопки «Выбрать А/Б/В» отмечают предпочтение только внутри страницы.

Все данные живут в памяти до закрытия/перезагрузки страницы. Сеть, proxy, DNS, firewall, реальные профили и подписки не затрагиваются. Задержки не изображаются как измеренные. TUN/DNS/Fake-IP помечены как планируемые; kill switch отражает намерение, а не применённую защиту. Изменения значений настроек — локальная демонстрация; обновление подписки только выводит пояснение.

Визуальное направление: спокойный минимализм; DFII 15 (воздействие 4, соответствие 5, реализуемость 5, производительность 5, риск согласованности 4). Палитра взята из утверждённого `docs/specs/ui-direction.md`: фон `#070707`, поверхность `#191919`, текст `#f3f4f6`, вторичный `#9ba1ab`, граница `#29262e`, акцент `#c3a6ef` / `#c9b6ef`. Onest — основной текст, Unbounded — заголовок и собственный wordmark tofu. Ритм отступов 4/8 px; движение ограничено наведением, reduced motion учитывается. Узнаваемость создают почти чёрное пространство, собственный знак tofu и лавандовая круглая кнопка, без декоративного дашборда.

Прототип предназначен для выбора направления до переноса в основной GUI. Он не подтверждает работу будущих сетевых режимов, производительность toolkit или системную доступность нативного приложения.

Шрифты встроены в HTML как WOFF2: кириллица U+0400–04FF, Latin-1, тире, многоточие, маркер списка и знак номера. Исходные переменные TTF, лицензии OFL и закреплённые URL/SHA-256 находятся в `assets/fonts/`; подмножества получены fonttools 4.62.1 с Brotli. Шрифты системы не изменялись.
